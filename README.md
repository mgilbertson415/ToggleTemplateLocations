# ToggleTemplateLocations
## SW macro to change file locations to site-specific presets

Run the macro. A userform will offer buttons for several different sites. Click any button to switch to that site's "File Locations" settings for:
- Document Templates
- Sheet Formats
- Custom Property Files

Also, the userform shows the user's current settings and tries to match them up with one of the available presets (Anoka, Bangalore, Straubenhardt as of v1.0, although the Bangalore listing is an empty shell so far)
